  1. はじめての PENPOT

    画面修正を、ひとつずつ。
    申請者登録の練習用デザインで
    見出しとボタンの色を変更します。

  2. 01 / 06 画面の見方

    中央はデザイン、左は部品の一覧「レイヤー」。
    右のパネルで、色や文字の見た目を調整します。

  3. 01 / 06 画面の見方

    今回は「見出し」と「進むボタン」を修正します。
    練習用ページなので、まずは操作に慣れましょう。

  4. 02 / 06 見出しを変更

    左の「Board」の矢印を押すと、
    画面を構成する文字や図形が表示されます。

  5. 02 / 06 見出しを変更

    「申請者登録」の文字レイヤーを選択します。
    選択した部品には、枠が表示されます。

  6. 02 / 06 見出しを変更

    Enterキーで文字の編集を開始。
    Ctrl + A で文字全体を選び、新しい見出しを入力します。

  7. 02 / 06 見出しを変更

    Escキーで文字編集を終了します。
    見出しが「申請者情報の登録」に変わりました。

  8. 03 / 06 ボタンの色を変更

    次に、ボタンの背景になっている図形を選びます。
    文字と背景は、別々のレイヤーです。

  9. 03 / 06 ボタンの色を変更

    右側の「FILL」は、塗りつぶしの設定です。
    色コードを入力すると、狙った色に変更できます。

  10. 03 / 06 ボタンの色を変更

    青の 285E99 を、緑の 176B56 に変更。
    入力したら Enterキーで確定します。

  11. 03 / 06 ボタンの色を変更

    ボタンが緑に変わりました。
    文字が読みやすいか、画面全体の中でも確認します。

  12. 04 / 06 元に戻す・やり直す

    間違えても大丈夫。
    Ctrl + Z で、ひとつ前の状態に戻せます。

  13. 04 / 06 元に戻す・やり直す

    青に戻ったことを確認します。
    Ctrl + Shift + Z で、取り消した操作をやり直します。

  14. 05 / 06 保存と確認

    何もない場所をクリックして、選択の枠を外します。
    見出しとボタンを、変更前と見比べましょう。

  15. 05 / 06 保存と確認

    Penpotは変更を自動保存します。
    保存を待ち、ページを再読み込みして確認します。

  16. 05 / 06 保存と確認

    再読み込み後も、変更した見出しと色が残っています。
    これで、デザイン側の修正は完了です。

  17. 06 / 06 実際のアプリへ反映

    デザインの次は、コードの修正。
    Penpotの変更だけでは、アプリは変わりません。
    変更内容をCodexへ伝え、実装と動作確認を進めます。

  18. CODEXへの依頼例

    変更点を、具体的に伝えます。
    「申請者登録画面の見出しを『申請者情報の登録』に。
    進むボタンを #176B56 に変更し、
    PCとスマートフォンで表示・操作を確認してください。」

  19. 今回のおさらい

    選ぶ → 変える → 確認する
    文字は Enter で編集。色は FILL で変更。
    Ctrl + Z で戻し、最後に保存と見た目を確認。

これはPenpotでのデザイン修正の動画です。実際のアプリへの反映には、別途コード変更と検証が必要です。
